[구독한잔해]

사용자가 이용 중인 구독 서비스를 하나의 프로그램에서 관리하고,
결제 주기를 월 단위로 환산하여 구독 지출을 쉽게 확인할 수 있는 프로그램

0. 사양
    - Python 3.13.7 기반
    - CLI 환경에서 실행
    - 별도의 외부 라이브러리 설치 없이 실행 가능

1. 실행 방법
    - 구독한잔해 프로젝트2 폴더에 있는 main.py를 VSCode에서 열어 실행하거나
      터미널에서 python main.py를 입력하여 실행한다

2. 주요 기능

    2.1 기능
    - 구독 등록 및 관리
        : 서비스명, 요금, 결제 주기, 다음 결제 예정일, 카테고리, 마지막 이용일,
          무료체험 종료일, 공유 인원수를 입력하여 구독 정보를 등록하고 조회 및 삭제한다.

    - 결제 주기 정규화
        : 월간, 연간, 4주 단위로 결제되는 구독 비용을 월 단위 비용으로 환산하고,
          전체 월 지출과 카테고리별 월 지출을 출력한다.

    - 해지 후보 탐지
        : 마지막 이용일을 기준으로 장기간 사용하지 않은 구독을 확인하고,
          무료체험 종료일이 있는 경우 D-day를 출력한다.

    - 체감 지출 리포트
        : 월 구독 비용을 이용하여 연간 예상 지출액을 계산하고,
          해당 금액을 커피 가격을 기준으로 환산하여 출력한다.

    - 분담비용 계산기
        : 선택한 구독의 월 환산 비용과 공유 인원수를 이용하여
          1인당 부담해야 하는 금액을 계산한다.

    2.2 모듈
    - main.py : 프로그램 실행 및 메인 메뉴를 관리한다.
    - shared_cost_calculator.py : 구독 서비스의 1인당 분담비용을 계산한다.
    - 그 외 각 기능별 모듈을 통해 구독 등록, 조회, 삭제, 결제 주기 정규화,
      체감 지출 리포트 등의 기능을 수행한다.

3. 파일 저장 구조
    - 구독 정보는 subscriptions.json 파일에 저장한다.
    - 서비스명을 Key로 사용하고 요금, 결제 주기, 다음 결제 예정일, 카테고리,
      마지막 이용일, 무료체험 종료일, 공유 인원수를 저장한다.
    - 프로그램 실행 시 기존 데이터를 불러오고 저장 후 종료 시 JSON 파일에 저장한다.
 4. 테스트 방법

    4.1 정상적인 구독 관리 및 비용 확인

        1) 구독이 없는 상태에서 프로그램을 실행한다.

        2) 다음 6개의 구독을 등록한다.

           - 넷플릭스 / 17,000원 / 월간 / 2026-09-15 / OTT / 2026-08-20 / 무료체험 없음 / 2명
           - 유튜브 프리미엄 / 14,900원 / 월간 / 2026-09-20 / 영상 / 2026-09-01 / 무료체험 없음 / 1명
           - Microsoft 365 / 119,000원 / 연간 / 2027-03-01 / 생산성 / 2026-08-10 / 무료체험 없음 / 1명
           - 멜론 / 10,900원 / 월간 / 2026-09-18 / 음악 / 2026-07-25 / 무료체험 없음 / 1명
           - 테스트 4주 구독 / 12,000원 / 4주 / 2026-09-25 / 기타 / 2026-09-05 / 무료체험 없음 / 1명
           - 테스트 OTT 구독 / 10,000원 / 월간 / 2026-09-22 / OTT / 2026-08-01 / 2026-09-20 / 1명

        3) 구독 조회를 실행하여 등록한 6개의 구독이 정상적으로 출력되는지 확인한다.

        4) 해지 후보 탐지가 자동으로 실행되는지 확인한다.
           기준일을 2026-09-09로 할 경우 멜론과 테스트 OTT 구독만
           해지 후보로 출력되는지 확인한다.
           정확히 30일이 지난 Microsoft 365는 해지 후보에서 제외되는지 확인한다.

        5) 테스트 OTT 구독의 무료체험 종료일까지 남은 기간이
           D-11로 출력되는지 확인한다.

        6) 결제 주기 정규화를 실행하여
           전체 월 지출이 약 75,716.67원으로 계산되는지 확인한다.

        7) OTT 카테고리의 넷플릭스와 테스트 OTT 구독 비용이 합산되어
           27,000원으로 출력되는지 확인한다.

        8) 체감 지출 리포트를 실행하여
           연간 예상 지출액이 908,600원,
           커피 환산 결과가 약 181.72잔으로 출력되는지 확인한다.

        9) 분담비용 계산기에서 넷플릭스를 선택하여
           공유 인원수 2명을 기준으로 1인당 월 실부담액이
           8,500원으로 출력되는지 확인한다.

        10) Microsoft 365를 삭제한 후 다시 조회하여
            나머지 5개의 구독만 출력되는지 확인한다.


    4.2 잘못된 입력 및 예외 처리

        1) 등록된 구독이 없는 상태에서 구독 조회를 실행하여
           "등록된 구독이 없습니다."라는 안내가 출력되는지 확인한다.

        2) 등록된 구독이 없는 상태에서 결제 주기 정규화를 실행하여
           "등록된 구독이 없습니다."라는 안내가 출력되는지 확인한다.

        3) 구독 등록에서 서비스명으로 디즈니플러스를 입력한다.

        4) 요금에 "만원"을 입력하여 숫자가 아닌 값에 대한
           재입력 안내가 출력되는지 확인한다.

        5) 요금에 -9900을 입력하여 음수 요금에 대한
           재입력 안내가 출력되는지 확인한다.

        6) 정상 요금 9900을 입력한 후 결제 주기에 "매주"를 입력하여
           허용되지 않은 결제 주기에 대한 안내가 출력되는지 확인한다.

        7) 결제 주기를 월간으로 다시 입력한다.

        8) 다음 결제 예정일에 "2026/09/20"을 입력하여
           잘못된 날짜 형식에 대한 안내가 출력되는지 확인한다.

        9) 다음 결제 예정일에 "2026-02-30"을 입력하여
           존재하지 않는 날짜에 대한 안내가 출력되는지 확인한다.

        10) 정상 날짜인 "2026-09-20"을 입력한다.

        11) 공유 인원수에 "두명", 0, 1.5를 차례로 입력하여
            각각 잘못된 입력으로 처리되고 재입력을 요구하는지 확인한다.

        12) 공유 인원수에 2를 입력하여 정상적으로 등록되는지 확인한다.

        13) 같은 서비스명인 디즈니플러스를 다시 등록하려고 할 때
            중복 안내가 출력되고 기존 데이터가 유지되는지 확인한다.

        14) 분담비용 계산기에서 디즈니플러스를 선택하여
            공유 인원수 2명을 기준으로 월 실부담액이
            4,950원으로 출력되는지 확인한다.

        15) 존재하지 않는 서비스명 또는 빈 값을 분담비용 계산기에 입력했을 때
            프로그램이 종료되지 않고 안내 메시지를 출력하는지 확인한다.

        16) 등록된 구독이 없는 상태에서 분담비용 계산기를 실행했을 때
            "등록된 구독이 없습니다."라는 안내가 출력되고
            메인 메뉴로 돌아가는지 확인한다.

        17) 등록되지 않은 "웨이브"를 삭제하려고 할 때
            존재하지 않는 서비스라는 안내 메시지가 출력되는지 확인한다.

        18) 디즈니플러스를 삭제하여 정상적으로 제거되는지 확인한다.


    4.3 데이터 저장 및 재실행

        1) 구독이 없는 상태에서 테스트용 6개 구독을 모두 등록한다.

        2) 0번 저장 후 종료를 선택하여 프로그램을 정상 종료한다.

        3) subscriptions.json 파일을 열어
           6개의 서비스 정보가 저장되었는지 확인한다.

        4) 각 서비스에 요금, 결제 주기, 다음 결제 예정일,
           카테고리, 마지막 이용일, 무료체험 종료일,
           공유 인원수 정보가 저장되었는지 확인한다.

        5) 무료체험 종료일을 입력하지 않은 서비스는
           null 값으로 저장되는지 확인한다.

        6) 프로그램을 다시 실행한다.

        7) 별도의 구독 등록 없이 기존 6개의 구독이
           정상적으로 조회되는지 확인한다.

        8) 불러온 데이터를 이용하여 해지 후보와
           무료체험 D-day가 정상적으로 계산되는지 확인한다.

        9) 넷플릭스의 저장된 공유 인원수 2명을 이용하여
           분담비용 계산 결과가 8,500원으로 출력되는지 확인한다.

        10) Microsoft 365를 삭제한 뒤 저장 후 종료한다.

        11) 프로그램을 다시 실행하여
            Microsoft 365는 나타나지 않고
            나머지 5개의 구독 데이터는 유지되는지 확인한다.
